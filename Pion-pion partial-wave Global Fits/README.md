# Pion-Pion Global Fits

Here we provide the dispersively constrained Global Fits of pion-pion partial waves developed by our group, available in both Python and Mathematica. The parametrizations and parameter values correspond to those published in:

J. R. Peláez, P. Rabán and J. Ruiz de Elvira, [“Global parametrizations of pion-pion scattering with dispersive constraints: Beyond the S0 wave”](https://doi.org/10.1103/PhysRevD.111.074003), *Phys. Rev. D* **111**, 074003 (2025).
